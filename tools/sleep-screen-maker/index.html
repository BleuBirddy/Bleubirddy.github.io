Put it on your Supernote

  1. Copy the PNG onto your Supernote, for example into the Document folder over USB.
  2. Swipe down from the top of the screen and tap Settings → Display & Input → Screensaver.
  3. Tap More, browse to the file and tap it. Leave it at Fill (the image is already sized to the screen), then tap OK.

You get a grayscale PNG at the screen's native resolution. The device does its own shading, so the preview shows smooth gray rather than a fixed set of shades.

Put it on your Kobo

  1. Connect the Kobo to your computer with USB and tap Connect on the reader.
  2. Open the .kobo folder on the Kobo drive and create a folder named screensaver (lowercase). It's a hidden folder: on a Mac press Cmd+Shift+. to show it; on Windows turn on hidden items.
  3. Copy the PNG into .kobo/screensaver. Add more images if you like; the Kobo picks one at random.
  4. Eject the Kobo, then go to Settings → Energy saving and privacy and turn on Show book covers full screen. If your image doesn't appear, some people find it works with that setting off instead.

This uses the Kobo's own firmware with no mods. On Colour models the image is still grayscale.

Put it on your Kindle

  1. Jailbroken Kindle with a screensaver hack: copy the PNG into the hack's screensaver folder (for the classic ScreenSavers hack, linkss/screensavers), then follow that hack's steps to apply it.
  2. Stock Kindle: Amazon doesn't let you load a custom screensaver. The closest you can get is Display Cover, which shows the cover of the book you're reading. Make this image the cover of a book (Calibre can do it), send it to your Kindle, open it, and turn on Display Cover in Settings. Ad-supported Kindles need ads removed first.

Kindle screensaver hacks need an 8-bit grayscale PNG at the screen's exact resolution. Other PNGs can make some Kindles freeze when they sleep. This file is saved in exactly that format.

Put it on your reader

  1. Copy the file to your SD card. Name it sleep.bmp in the root folder to use just this one, or put any number of BMPs in a folder named .sleep and CrossPoint picks one at random each time.
  2. On the reader, open Settings → Display → Sleep Screen and choose Custom.
  3. Put the reader to sleep to see it.

The file is saved with a palette of exactly the panel's four grays. CrossPoint draws images like that pixel for pixel. A regular 24-bit BMP gets dithered again on the device, so it won't match what you previewed.
